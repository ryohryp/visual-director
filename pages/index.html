Standard flow

Plus-first generation

  1. Game repositoryVisual Canon, Approved Anchors, global references
  2. .visual-director/compiled-canon.jsonDeterministic, repository-stored generation contract
  3. ChatGPT + GitHubResolve project, subject, references, policy, and request-time scene requirements
  4. Image generationGenerate only after required references and fail-closed policy checks succeed
  5. Human reviewGenerated output remains subject to explicit review and adoption

Compiled Canon checks

Before generation

  • project_id matches the requested project
  • asset_type is supported by the compiled rules
  • requested subject_ids resolve when required
  • Approved Anchor path exists for locked subjects
  • global reference path resolves when required
  • policy.must_use_approved_anchor is enforced
  • forbidden changes are rejected rather than silently relaxed

Failure taxonomy

Keep failures separate

Canon failure
Missing or invalid required visual source-of-truth data. Generation must fail closed.
Repository failure
GitHub access, file resolution, or repository state prevents validation. Do not treat as Canon success.
MCP failure
Transport, session, or hosted runtime failure. Repository-native generation may continue when its own checks succeed.
